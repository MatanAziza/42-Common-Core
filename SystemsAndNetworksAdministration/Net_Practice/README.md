# Net Practice

## Description

This project aims to teach how TCP/IP addressing, subnet masks\
and such concepts works. To do so, the learner gets 10 exercises to practice\
these concepts from connecting 2 interfaces to setting up many routers and\
switches to Internet. Each exercice, once solved, provides a config.json file\
than contains all set-ups the learner did on these exercises.

## Instructions

To practice or be evaluated, the learner needs only one thing:

- Download the resource given in the project
- Right click on the index.html file and open it in a Chromium/Edge browse\
(Firefox won't make the files works properly).

Once on the index.html page, the learner has the choice between practice\
(and exporting his practice files once he's correct), and starting the evaluation mode,\
and being tested on 3 level between 6 and 10 for a macimum duration of 15 min.
